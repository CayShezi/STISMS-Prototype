# STISMS Prototype

STISMS Prototype is a standalone clickable concept project for the Smart Taxi Innovation & Safety Management System. It is intentionally separate from the production repository and focuses on:

- role-first user journeys
- regulator compliance oversight
- learner transport operations
- parent and passenger safety/payment flows
- a lighter, presentation-friendly prototype surface

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- This prototype is frontend-only.
- It uses curated demo content instead of the live STISMS backend.
- It is designed for walkthroughs, stakeholder reviews, and early UX validation.
